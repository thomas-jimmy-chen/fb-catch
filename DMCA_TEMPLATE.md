# DMCA Takedown Notice Template | DMCA 撤除通知範本

> **用途**：若發現有人將 FB Catch 或其修改版上傳至 Chrome Web Store
> 或其他平台，使用此範本快速提交 DMCA 撤除通知。
>
> **提交位置**：
> - Chrome Web Store: https://support.google.com/legal/troubleshooter/1114905
> - GitHub: https://support.github.com/contact/dmca-takedown
> - 一般平台: 尋找該平台的 Copyright / DMCA 頁面

---

```

   - Copyright holder: Thomas Chen

     (prohibits redistribution and republication)

2. INFRINGING MATERIAL

   The following material infringes my copyright:

   - URL: [URL of the infringing extension/page]
   - Name: [Name used by the infringing extension]
   - Developer: [Developer name/email if visible]
   - Description: [Brief description of the infringement — e.g.,
     "This is a verbatim copy of my extension uploaded without
     authorization" or "This is a modified version of my extension
     republished in violation of the license"]

3. EVIDENCE OF OWNERSHIP

   - I am the sole author and copyright holder of FB Catch.
   - The official source code is hosted at
     https://github.com/thomas-jimmy-chen/fb-catch
   - The LICENSE file explicitly prohibits redistribution to any
     third party, including uploading to the Chrome Web Store or
     any browser extension marketplace (Section 3(a)).
   - [Optional: specific code signatures, unique variable names, or
     identical comments that prove the infringing work is derived
     from my original]

4. GOOD FAITH STATEMENT

   I have a good faith belief that use of the copyrighted material
   described above is not authorized by the copyright owner (myself),
   its agent, or the law.

5. ACCURACY STATEMENT

   I swear, under penalty of perjury, that the information in this
   notification is accurate and that I am the copyright owner or am
   authorized to act on behalf of the owner of an exclusive right
   that is allegedly infringed.

6. CONTACT INFORMATION

   Full name: Thomas Chen
   Email: [YOUR EMAIL]
   Address: [YOUR ADDRESS]
   Phone: [YOUR PHONE] (optional)

   Electronic signature: /s/ Thomas Chen
   Date: [YYYY-MM-DD]
```

## 撤除通知範本（中文版）

```
DMCA 撤除通知

日期：[YYYY-MM-DD]

1. 被侵害之著作

   被侵害之著作為「FB Catch」，一款用於匯出 Facebook 貼文與
   留言的 Chrome 瀏覽器擴充功能。

   - 著作權人：Thomas Chen
   - 官方儲存庫：https://github.com/thomas-jimmy-chen/fb-catch
   - 授權條款：FB Catch Source Available License v1.0
     （明確禁止再散布與重新發布）

2. 侵權素材

   以下素材侵害本人著作權：

   - 網址：[侵權擴充功能/頁面之 URL]
   - 名稱：[侵權擴充功能使用之名稱]
   - 開發者：[開發者名稱/email（如可見）]
   - 說明：[侵權描述——例如：「此為本人擴充功能之完整複製，
     未經授權即上傳」或「此為本人擴充功能之修改版本，
     違反授權條款重新發布」]

3. 所有權證明

   - 本人為 FB Catch 之唯一作者及著作權人。
   - 官方原始碼託管於
     https://github.com/thomas-jimmy-chen/fb-catch

   - [可選：特定的程式碼簽章、獨特變數名、或相同註釋，

   電話：[你的電話]（選填）

   電子簽名：/s/ Thomas Chen
   日期：[YYYY-MM-DD]
```

## Quick Checklist | 快速檢查清單

Before submitting, verify: | 提交前確認：

- [ ] Screenshot of the infringing listing | 侵權頁面截圖
- [ ] Screenshot of your original GitHub repo with commit history |
      你的 GitHub 原始 repo 截圖（含 commit 歷史）
- [ ] Diff or code comparison showing copied content |
      程式碼比對，顯示複製內容
- [ ] Link to your LICENSE file on GitHub |
      你的 LICENSE 檔案 GitHub 連結
- [ ] Your contact information is filled in |
      聯繫資訊已填寫

## Response Timeline | 回應時間

| Platform | Expected Response |
|----------|------------------|
| Chrome Web Store | 3-10 business days |
| GitHub | 1-3 business days |
| Other platforms | Varies |

If the infringing party files a counter-notice, the platform typically
waits 10-14 business days before taking further action. Prepare to
escalate to legal counsel if needed.

若侵權方提出反通知，平台通常會等 10-14 個工作天後才採取進一步行動。
如有需要，請準備諮詢法律顧問。
